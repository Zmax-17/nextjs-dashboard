# Next.js Dashboard Application

A full-stack dashboard application built as part of the official [Next.js App Router Course](https://nextjs.org).

## Features

- 🗺️ **App Router:** Utilizing optimized folder structure, nested layouts, and pages.
- 🎨 **Styling:** Tailwind CSS integration and font optimization with `next/font`.
- 🖼️ **Image Optimization:** Implementing the `next/image` component for responsive images.
- 🗄️ **Database:** In progress of connecting a PostgreSQL database.

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
